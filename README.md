# 🌍 Countries Data Analysis

A beginner-friendly Exploratory Data Analysis (EDA) project using Python, NumPy, and Pandas to explore country-level information.

## Project Overview

The goal of this project is to explore a countries dataset and answer interesting questions about population, democracy scores, geographical regions, and political leadership.

## Technologies Used

- Python
- NumPy
- Pandas
- Jupyter Notebook

## Analysis Performed

1. Identified the country with the highest population.
2. Identified the country with the lowest population.
3. Found the capital cities of both countries.
4. Retrieved the top 5 countries by democracy score.
5. Analyzed the distribution of countries across regions.
6. Explored countries in Eastern Europe.
7. Identified the political leader of the second most populated country.
8. Checked countries with missing political leadership information.
9. Explored countries containing "Republic" in their names.
10. Identified the most populated country in Africa.

## Key Concepts Practiced

- DataFrame exploration
- Data filtering and sorting
- Handling missing values
- String operations
- Aggregation and data selection

## Learning Outcome

This project helped me gain practical experience with Pandas and understand how to extract meaningful information from raw datasets.

This is part of my ongoing journey toward Data Science and Machine Learning.
